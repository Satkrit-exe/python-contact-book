# 📒 Python Contact Book

A simple command-line Contact Book application built with Python. This project helps beginners practice fundamental Python concepts while creating a practical application.

---

## 🚀 Features

- ➕ Add new contacts
- 📋 View all saved contacts
- 🔍 Search contacts by name
- ❌ Delete contacts
- 💾 Store contacts using file handling
- 🖥️ Easy-to-use command-line interface

---

## 🛠️ Built With

- Python 3
- File Handling
- Functions
- Loops
- Conditional Statements
- String Manipulation

## ▶️ Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/python-contact-book.git
```

### Navigate to the project

```bash
cd python-contact-book
```

### Run the application

```bash
python contact_book.py
```
